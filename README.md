## Overview
This repository contains the assignments and project work for the **Programming for Data Analytics** module at **Atlantic Technological University, Galway**.  
The module is part of the *Level 8 Higher Diploma in Computational and Data Analytical Science* program.

The purpose of this repository is to organize and showcase coursework completed throughout the module. It includes Python-based assignments and a final project focused on data analytics techniques.

This project explores the global prevalence of Type 2 Diabetes (T2D) through exploratory data analysis.

#### Data source and methodology
The data used for this project comes from [Global Health Data Exchange (GHDx)](https://ghdx.healthdata.org/), a publicly available resource provided by the Institute for Health Metrics and Evaluation (IHME), an independent global health research center at the University of Washington.
IHME focuses on delivering rigorous and comparable measurements of the world’s most significant health problems and evaluating strategies to address them.
The datasets used in this project consists of estimates, which are standalone values that may originate from underlying datasets used in publications or created independently for research purposes. These estimates include IHME results and differ from reports in that they contain minimal or no narrative—primarily numerical data intended for analysis.

To identify trends and risk factors, we utilise the following analytical tools:
**Line Plots:** To illustrate T2D prevalence across different age groups, segmented into five-year increments.
**Choropleth Maps:** To visualise the geographical distribution and intensity of T2D prevalence across the globe.
**Scatter Plots:** To perform a comparative analysis of prevalence rates between males and females.
**Time-Series Analysis:** Using line plots to track regional T2D trends and shifts from 1990 to 2023.
**Multiple Linear Regression:** To identify and analyse the key predictors and variables influencing the spread of the disease.
